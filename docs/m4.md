# M4 — AArch64 dom0less Linux

M4 extends the combined ELF from Xen-only boot to one static Arm DomU.

## Build inputs

- `xloader-aarch64.elf` — built by this repository
- Xen AArch64 ELF — prebuilt binary imported into the Nix store
- Linux AArch64 `Image` — taken directly from pinned `nixos-26.05-small`

No Xen or Linux source rebuild is part of this workflow.

## Bundle construction

`xbundle build` accepts one raw Linux kernel payload:

```sh
xbundle build \
  --loader build/xloader-aarch64.elf \
  --xen "$XEN_IMAGE" \
  --domu-kernel "$LINUX_IMAGE" \
  --domu-memory-mb 256 \
  --domu-vcpus 1 \
  --xen-base 0x40200000 \
  -o build/system-aarch64.xbundle.elf
```

The host tool places the Linux payload after Xen at the next 2 MiB boundary and
adds a read-only `PT_LOAD` entry for it. Domain 0 in the xbundle descriptor is
patched with the final physical address and exact kernel size.

## Runtime DT

xloader copies the QEMU machine DTB into its private libfdt workspace and adds:

```dts
/chosen {
    xen,xen-bootargs = "console=dtuart dtuart=serial0";

    domU0 {
        #address-cells = <1>;
        #size-cells = <1>;
        compatible = "xen,domain";
        memory = <0 0x40000>; /* 256 MiB in KiB */
        cpus = <1>;
        vpl011;

        module@0 {
            compatible = "multiboot,kernel", "multiboot,module";
            reg = <KERNEL_PA KERNEL_SIZE>;
            bootargs = "console=ttyAMA0 earlycon=xen";
        };
    };
};
```

The kernel `reg` size is the exact byte size of the Nix-store Linux `Image`.

## Acceptance

```sh
make bundle-aarch64
make inspect-bundle-aarch64
make smoke-xen-aarch64
```

The smoke test requires all of:

```text
xloader: DomU0 kernel ...
xloader: entering Xen
(XEN) ...
Linux version ...
```

M4 intentionally has no initramfs. Linux may eventually panic because no root
filesystem is supplied; reaching the Linux kernel console proves the dom0less
launch path. M5 will add a small Nix-store initramfs and boot to a shell.
